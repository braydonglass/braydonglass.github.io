02  Work

AI-Council

In development

A local AI software team. One agent writes, one reviews, one tests, and they hand work between them instead of one model trying to do all three in a single pass. It runs on my own machine through Ollama, so there's no API bill and nothing leaves the box.

What I'm actually designing is the org chart. Who speaks first, what each agent is allowed to see, and what happens when the reviewer and the writer disagree. Averaging the two answers is the obvious move and it's the wrong one, because you end up with something neither agent would have put its name on. So the reviewer holds a veto and has to state a reason, and the writer gets another pass. Most of the project is that one rule, worked out properly.

The Cepa 82

Live

A product page for a yellow onion, art-directed like a watch campaign and played completely straight. Black field, Playfair display type, one gold accent lifted off the skin. It only works because it never winks.

The rule I set was that every claim on the page has to be true of Allium cepa. Eleven concentric scales. 8.2 µmol of pyruvate per gram. Three outer scales dried down into the tunic. Once the spec sheet is real, it stops being a joke about onions and turns into a joke about product pages.

I ruled out a video element early, because video seeking stutters the moment you tie it to scroll. So the bulb is 144 stills painted to a canvas and indexed by scroll position, with a requestAnimationFrame loop reading layout rather than listening for scroll. The camera circles the bulb while it's whole, then opens it: every layer drifting out along its own radial axis, evenly spaced, nothing torn.

Local Image-to-3D

3D pipeline

Drop in a photograph, get back a textured 3D model light enough to put on a web page. Shape generation and texturing both run here on my own GPU, so there's no per-asset cost and nothing gets uploaded. Source on GitHub.

The hardware forced the interesting decision. Every mature tool for the texturing half assumes an NVIDIA-only rasteriser, and this machine is AMD. Rather than fight that, I split the pipeline down the middle: the AI half runs on the GPU, the geometry half goes through plain OpenGL, which doesn't care whose card it is.

The call I'd defend in an interview is the symmetry handling. A fish photographed side-on has a far flank that mirrors the near one, so copying it is correct rather than guessed. A person doesn't work that way. The shape model produces near-symmetric geometry either way, because it has no data for the back, and no measurement can tell those two cases apart. So it mirrors only when told to. By default it refuses.
